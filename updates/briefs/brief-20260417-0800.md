# 4月17日 AI 速报 · 第 211 期

## Summary

Anthropic 正式发布 Claude Opus 4.7，以显著增强的任务韧性、视觉推理能力和「敢于反驳用户」的可靠性著称；与此同时，Codex 连续迭代，突破沙盒限制并上线应用内浏览器+评论模式，大幅拓展 AI 编程场景边界 [1][2][3]。Anthropic 同步为付费用户永久上调速率限制，以应对新模型更高的思考 token 消耗 [5]。

## Content

## 🔍 核心洞察  
Anthropic 正式发布 **Claude Opus 4.7**，以显著增强的**任务韧性**、**视觉推理能力**和「敢于反驳用户」的可靠性著称；与此同时，**Codex** 连续迭代，突破沙盒限制并上线**应用内浏览器+评论模式**，大幅拓展 AI 编程场景边界 [1][2][3]。Anthropic 同步为付费用户**永久上调速率限制**，以应对新模型更高的思考 token 消耗 [5]。

## 🚀 重点动态  
- **Claude Opus 4.7 发布：不是最强，但更「靠谱」** [1]：新增代码生成鲁棒性、多模态工具调用与主动纠错能力，强调“可信执行”而非单纯性能突破  
- **Codex 现已具备类似 Cowork 的能力且不受沙盒限制** [2]：支持跨应用自主操作与长周期任务编排，摆脱传统安全沙盒对功能的制约  
- **Codex 上线应用内浏览器与评论模式** [3]：编辑器内直连网页，自动捕获 DOM 与屏幕内容作为上下文，实现所见即交互  
- **Claude Opus 4.7 消耗更多思考 token，Anthropic 已上调付费用户速率限制** [5]：所有 Pro 订阅用户获得永久性速率配额提升，补偿推理开销增长  
- **Claude Opus 4.7 深度使用技巧与工作流优化指南** [4]：涵盖自动模式、专注模式、努力程度调节及自我验证等进阶策略，提升工程落地效率  
- **卸载龙虾后，我找到了更香的爱马仕 Agent，5 分钟带你极速上手** [6]：Hermes Agent 全平台（本地/云/安卓）部署教程，强调轻量、可控与可解释性优势
