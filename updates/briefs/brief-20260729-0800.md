# 7月29日 AI 速报 · 第 520 期

## Summary

MCP 协议正式转向无状态架构，为 serverless 与边缘计算铺路；OpenAI 开源 Codex Security，首次以 Apache-2.0 协议释放 AI 原生代码安全能力；Kimi K3 开源加速行业博弈，倒逼 Anthropic 等闭源厂商公开表态，凸显开源模型对商业生态的结构性冲击 [1][3][9]。

## Content

## 🔍 核心洞察  
**MCP 协议**正式转向**无状态架构**，为 serverless 与边缘计算铺路；**OpenAI 开源 Codex Security**，首次以 Apache-2.0 协议释放 AI 原生代码安全能力；**Kimi K3 开源**加速行业博弈，倒逼 Anthropic 等闭源厂商公开表态，凸显**开源模型对商业生态的结构性冲击** [1][3][9]。

## 🚀 重点动态  
- **MCP 协议 2026-07-28 版本发布：从有状态转向无状态，支持 serverless 与边缘计算** [1]：核心协议升级为无状态请求/响应范式，显著提升横向扩展性与轻量部署能力。  
- **OpenAI 开源 Codex Security：AI 驱动的代码安全扫描工具正式发布** [3]：将原闭源插件独立为开源项目，支持漏洞识别、上下文感知修复建议及 CI/CD 集成。  
- **Kimi K3 一开源，Anthropic 终于不装了** [9]：Kimi K3 权重与训练细节公开后，Anthropic 首次明确否认“反对开源”立场，英伟达同步推动开放权重联盟。  
- **关于 PDF 输入 Token 的实用建议：不必过度转换** [5]：实测表明直接输入 PDF 比转 Markdown 更保真，且 Agent 的 Token 消耗主因在技能调用而非原始文档解析。  
- **uv 0.12.0 发布：默认项目结构切换为 src/ 布局** [4]：引入破坏性变更，“uv init” now generates `src/`-based projects with `uv_build` backend and script aliases by default。  
- **模型使用心得：Fable 5 靠谱、GPT 5.6 Sol 高效、Opus 5 两头不沾** [2]：一线开发者实测对比三款主流模型，指出 Fable 5 在推理稳定性、Sol 在低延迟任务中具明显优势。  
- **揭秘 Emil AI Skills 营销套路：免费版作为钩子卖课** [8]：公开版功能受限严重，中文社区大量传播实为流量转化闭环，课程变现路径清晰。
