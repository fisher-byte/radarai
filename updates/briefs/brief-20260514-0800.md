# 5月14日 AI 速报 · 第 292 期

## Summary

DAA（日活智能体数） 被李彦宏正式提出为AI应用价值新标尺 [4]；MiniMax 发布 Mavis 多 Agent 系统，以 Leader-Worker-Verifier 对抗式架构直击长程任务中的上下文焦虑与模型不可控顽疾 [0]；全球头部厂商正加速从单点模型能力转向全栈 Agent OS 与系统级智能体化引擎布局 [5]。

## Content

## 🔍 核心洞察  
**DAA（日活智能体数）** 被李彦宏正式提出为AI应用价值新标尺 [4]；**MiniMax** 发布 Mavis 多 Agent 系统，以 Leader-Worker-Verifier 对抗式架构直击长程任务中的**上下文焦虑**与**模型不可控**顽疾 [0]；全球头部厂商正加速从单点模型能力转向**全栈 Agent OS** 与**系统级智能体化引擎**布局 [5]。

## 🚀 重点动态  
- **MiniMax 推出 Mavis 多 Agent 系统** [0]：采用 Leader-Worker-Verifier 对抗架构与上下文隔离设计，显著提升长程任务可控性与稳定性  
- **Anthropic 收紧 Claude 订阅共享机制** [1]：6月15日起为 Agent SDK 等程序化调用设置独立月度 credit 额度，实质强化商业化管控  
- **李彦宏首提 DAA（日活智能体数）指标** [4]：在 Create 2026 大会定义 AI 应用价值新范式，强调智能体自我进化与组织级变革  
- **MediaTek 发布天玑 AI 智能体化引擎 2.0** [5]：覆盖手机、汽车、IoT 与游戏场景，推动端侧算力向系统级 Agent OS 演进  
- **LandingAI 推出 ADE Classify 页面级分类 API** [6]：在文档解析前对 PDF 逐页分类，有效降低算力浪费与抽取幻觉风险  
- **百度秒哒 3.0 升级为生产级 AI 应用平台** [9]：支持原生 APP 生成、企业协作与 Agent 工作流，将开发门槛从专业开发者下沉至大众用户  
- **字节跳动提出视觉生成新范式 GRN** [10]：融合扩散与自回归优势，实现“边画边改、简单少画复杂多画”的人类式生成逻辑  
- **林俊旸创业聚焦世界模型与具身大脑** [15]：新公司估值约 20 亿美金，获红杉中国等机构早期接触，锚定 AGI 基础架构赛道
