## 🔍 核心洞察  
**Anthropic** 推出面向小企业的 Claude 专用版本并新增**程序化调用专用额度**，**OpenAI** 加速企业迁移落地 Codex 沙箱技术，而前 Meta FAIR 总监**田渊栋**官宣新公司 **Recursive**，聚焦**递归自改进超智能**，获**6.5 亿美元融资**[7][4][9][3]。

## 🚀 重点动态  
- **Anthropic 推出 Claude for Small Business** [4]：集成 QuickBooks、PayPal 等 15 个预设技能，零额外收费  
- **Anthropic 新增程序化调用专用额度** [9]：6 月 15 日起为所有付费计划开放，专用于 Agent SDK 与 Claude Code 调用  
- **OpenAI 为 Codex 构建 Windows 提权沙箱** [3]：实现 OS 级文件写入隔离与网络访问限制，强化 AI Agent 安全边界  
- **OpenAI 推出 Codex 企业迁移优惠** [8]：30 天内从 Claude Code 切换可享 2 个月免费使用权  
- **田渊栋联合创立 Recursive 公司** [7]：专注构建递归自改进超智能，已获超 6.5 亿美元融资  
- **baoyu-skills 新增微信群聊总结 Skill** [6]：依赖 wx-cli 数据读取，推荐 Claude Code + Opus 4.6 组合调用  
- **Shopify 工程师分享多 Agent 系统实战经验** [10]：验证“专才 Agent”优于“通才 Agent”，赋能领域专家更高效  
- **Towards Data Science 发布生产级 AI 智能体评估框架** [12]：基于 100+ 次部署提炼检索、生成、Agent 行为、生产四层共 12 项核心指标
