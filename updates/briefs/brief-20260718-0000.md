# 7月18日 AI 速报 · 第 486 期

## Summary

Agent 原生终端与MCP 接口标准正加速重构 AI 手机底层范式，阶跃星辰发布首款搭载 Step AOS 操作系统的 STEPX Neo，而新豆包手机则转向要求超级应用开放 MCP 协议以替代 GUI 自动化 [1][2]。

## Content

## 🔍 核心洞察  
**Agent 原生终端**与**MCP 接口标准**正加速重构 AI 手机底层范式，阶跃星辰发布首款搭载 **Step AOS** 操作系统的 **STEPX Neo**，而新豆包手机则转向要求超级应用开放 **MCP 协议**以替代 GUI 自动化 [1][2]。

## 🚀 重点动态  
- **阶跃星辰发布 Agent 原生手机 STEPX Neo** [1]：WAIC 2026 首发，搭载自研 Step AOS 系统，以智能体取代 App 成为交互入口  
- **新豆包手机转向 MCP 接口优先策略** [2]：放弃 GUI 自动化路径，要求头部应用提供标准化 MCP 接口，备货量升至数十万台  
- **新豆包获生成式 AI 备案资质** [2]：成为国内首批通过《生成式人工智能服务管理暂行办法》备案的 AI 手机项目  
- **Identity Skill 实现图像驱动网页精准还原** [3]：基于 Image2 生成分区参考图，并 1:1 还原为可交付网页，附逐区对照证据
