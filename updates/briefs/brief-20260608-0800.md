## Content

## 🔍 核心洞察  
OpenAI 正推进 **ChatGPT 史上最大改版**，将其从对话工具全面升级为集成**编程、Agent、图像生成与第三方应用**的超级智能体平台 [0][17]；与此同时，**Anthropic 内部 Skills 方法论首次公开**，为行业提供可复用的模型能力工程化范式 [7]，而其**Opus 4.7/4.8 性能滑坡已致 Notion 全面禁用 Anthropic 模型**，凸显大模型可靠性危机 [11]。

## 🚀 重点动态  
- **ChatGPT 将迎最大改版：从聊天工具变身超级应用** [0]：OpenAI 启动自2022年上线以来最深度重构，整合 Codex 等能力，迈向通用智能体平台。  
- **ChatGPT 将迎来史上最大改版，“AI 只用来聊天的时代结束了”** [17]：明确将编程、日程管理、软件操控等生产力功能深度内嵌，标志战略升维。  
- **重磅！Anthropic 内部 Skills 经验公开了！** [7]：首次披露 9 类 Claude Code Skills 划分逻辑、编写原则及团队治理机制，填补 Agent 能力工程化空白。  
- **Notion 因 Anthropic 模型性能下降禁用所有 Anthropic 模型** [11]：Opus 4.7/4.8 显著退化触发商业级信任危机，引发对模型迭代质量管控的行业反思。  
- **大厂的 Agent 竞争有了哪些新趋势｜窄播 Weekly** [2]：竞争主线已从 Coding Agent 扩展至**通用生产力场景**，聚焦产品整合、生态建设与上下文积累四大维度。  
- **Deep Research 能力对比：ChatGPT 最佳，Gemini 次之，Claude 较弱** [5]：宝玉实测指出 ChatGPT 在深度研究任务中综合表现最优，Gemini 搜索强但推理弱，Claude 明显滞后。  
- **OpenAI 芯片核心叛逃 Anthropic！就在量产前夜** [16]：自研芯片关键工程师 Clive Chan 离职加盟 Anthropic，折射巨头在**AI 芯片与底层架构**领域的白热化人才争夺。  
- **AI 不会合作？那是因为他们没见过市场经济｜Hao 好聊趋势** [14]：提出以**市场机制（拍卖、桶旅式支付）替代中央编排**，破解多 Agent 系统合作能力缺失的根本性训练范式缺陷。
