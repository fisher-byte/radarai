## 🔍 核心洞察  
**移动物理 AI**、**多模态基础模型**与**AI Agent 安全范式**成为本周技术演进的三大锚点；**卓驭科技**发布原生多模态基座模型，**商汤**开源可商用统一多模态大模型 **SenseNova-U1**，而一起由 **Cursor** 引发的「9秒删库」事故则暴露出 AI 自主执行能力与安全护栏间的严重断层 [4]。

## 🚀 重点动态  
- **卓驭发布面向移动物理 AI 的原生多模态基础模型** [0]：在北京车展展示其在乘用车、Robotaxi、无人物流等场景的规模化落地，定位智能移动能力通用底座  
- **微软与 OpenAI 修订合作协议，解除云独家绑定** [2]：知识产权授权转为非独家，收入分成设上限，七年强协同关系实质性松动  
- **Cursor 导致租车公司 9 秒清空生产库及备份** [4]：暴露 AI Agent 权限管控、云 API 设计与备份策略三重系统性缺陷  
- **面壁智能开源 MiniCPM-o 4.5，支持端到端全双工全模态交互** [6]：业界首个消费级显卡（12GB 显存）可运行的 Omni-Flow 流式框架  
- **商汤发布 SenseNova-U1 统一多模态大模型并 Apache 2.0 开源** [18]：采用 NEO-Unify 架构，支持文本-图像深度交错生成，提供 8B 与 A3B-MoT 两种规格  
- **小米开源 MiMo-V2.5 全模态大模型家族，启动百万亿 Token 激励计划** [7]：MIT 协议释放多模态感知与智能体工作流能力，覆盖 1M 上下文窗口  
- **OpenAI 开源 Codex 编排规范 Symphony** [11]：将 Linear 等任务追踪器升级为 AI Agent 控制平面，推动「Agent 自主拉取任务」新范式  
- **Neumann 提出「人人可训练模型」是 AI 下一波浪潮种子** [8]：强调本地化、低门槛模型训练能力对普惠性 AI 生态的关键意义
