# 5月28日 AI 速报 · 第 334 期

## Summary

Agent 工程化正加速从概念验证迈向生产落地，Alook开源平台实现 CLI Agent 的角色化编排，复旦 NLP团队为学术场景提供免费 GPU 支持的全自动科研 Agent；与此同时，小米将国产大模型 API 价格压至 0.025 元/百万 Token，行业进入深度“Token 价格战”阶段 [16]。

## Content

## 🔍 核心洞察  
**Agent 工程化**正加速从概念验证迈向生产落地，**Alook**开源平台实现 CLI Agent 的角色化编排，**复旦 NLP**团队为学术场景提供免费 GPU 支持的全自动科研 Agent；与此同时，**小米**将国产大模型 API 价格压至 **0.025 元/百万 Token**，行业进入深度“**Token 价格战**”阶段 [16]。  

## 🚀 重点动态  
- **RepoPrompt 作者加入 OpenAI，工具免费并即将开源** [0]：原作者正式加盟 OpenAI，RepoPrompt 即日起免费开放，付费用户获赠 Codex Credits。  
- **Alook 开源：将 CLI Agent 编排为可管理的 AI 团队** [13]：支持为 Claude Code 等本地 Agent 分配角色、邮箱与共享记忆，构建类组织协作架构。  
- **复旦 NLP 上线「切问学术」Agent，提供免费 GPU 科研自动化服务** [6]：覆盖论文复现、文献综述生成与研究计划制定，降低 AI 科研门槛。  
- **小米 MiMo-V2.5 API 最高降价 99%，锚定 0.025 元/百万 Token 基准线** [16]：通过缓存命中策略与工程优化，引爆国产大模型新一轮价格内卷。  
- **Spark AI 李智昊批判视频世界模型路线，力推 4D 点云技术路径** [14]：指出当前主流方案“不本质”，预测两年内将出现 4D 物理世界的 Stable Diffusion 时刻。  
- **OpenExO 创始人称 AI Agent 将“抹平中层管理”** [21]：Salim Ismail 提出企业需转向以智能为中心、去层级化的 AI Native 组织架构。  
- **OPPO ColorOS 16 定义手机 AI 新范式：最高境界是“仿佛没有 AI”** [5]：强调无感融合——用户仅在 AI 缺席时才察觉其存在。  
- **《Agent Harness Engineering》综述发布，提出 ETCLOVG 七层框架** [9]：系统论证模型外部的工程外壳（Harness）是 Agent 从 Demo 走向生产的关键分水岭。
