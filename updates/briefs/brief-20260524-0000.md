## 🔍 核心洞察  
AI 产业正加速从**模型层竞争**转向**系统层攻坚**：**DeepSeek** 推出永久降价的 V4-Pro 模型并启动「Harness」工程计划，对标 Claude Code；**Google** 发布 Gemini 3.5 与 Antigravity 2.0 智能体平台；而垂类创企如 **FlashLabs** 与 **invoko.ai** 则集体转向业务嵌入与C端落地，印证“**智能体必须长在自己的业务里**”已成为行业共识 [3][4][14][15][20]。

## 🚀 重点动态  
- **DeepSeek V4-Pro API 永久降价至原价 25%** [15]：大幅降低调用成本，加速模型规模化商用。  
- **DeepSeek 启动 Harness 计划，从零构建中国版 Claude Code** [20]：聚焦代码智能体的工程系统层，标志 AI 编程竞争升维。  
- **Google I/O 2026 发布 Gemini 3.5 与 Antigravity 2.0 智能体平台** [7]：强化长期任务执行、Web/Android 原生智能体开发支持。  
- **腾讯云 ADP 智能工作台实证：企业级智能体必须深度嵌入业务系统** [3]：拒绝独立聊天框，强调与 OA、CRM、ERP 的流程级耦合。  
- **invoko.ai 创始人复盘垂直 Agent 困局，转向 C 端浏览器插件路径** [0]：揭示 ToB 垂类 Agent 在通用模型冲击下的生存策略转型。  
- **FlashLabs 公布垂类 AI 创企系统性自救方案** [14]：涵盖组织重构、产品重定义与商业化模式切换三重调整。  
- **超聚变提交创业板 IPO 申请，拟募资 80 亿元投向新一代算力基础设施** [8]：国产 x86 服务器龙头加速自主算力底座建设。  
- **Codex 升级为“AI 员工”方法论公开：含持久线程、语音输入、Heartbeats 调度与共享记忆** [2][5]：Jason Liu 提出将编程助手进化为持续工作执行系统的完整框架。
