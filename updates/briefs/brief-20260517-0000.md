## 🔍 核心洞察  
AI 产业正加速从**模型能力竞赛**转向**系统级工程落地**与**生态安全治理**双轨并进：**Anthropic** 估值跃升至**9000 亿美元**超越 OpenAI [7]，而 **OpenAI 董事会首次公开披露智能体时代核心风险为提示注入攻击** [12]；与此同时，**字节火山引擎推出 Agent Plan** 实现文/图/视/码多模态一站式调用 [4]，**微信读书上线 Agent Skill** 推动内容平台深度 AI 原生化 [8]。

## 🚀 重点动态  
- **马耳他成为全球首个向全民免费发放 ChatGPT Plus 订阅的国家** [2]：启动「全民 AI」计划，同步提供 AI 素养课程  
- **字节火山引擎发布 Agent Plan** [4]：单 API Key 整合语言、图像、视频与代码生成能力，支持 Claude Code 等编码助手原生接入  
- **微信读书上线 Agent Skill 功能** [8]：AI Agent 可直接阅读、解析与推理电子书内容，标志内容平台进入 AI 服务化新阶段  
- **OpenAI 首设面向中文开发者的布道型技术职位** [9]：驻新加坡岗位，聚焦降低 Codex 等产品在华语区的使用门槛  
- **Anthropic 公开回应芯片困局** [11]：以千亿美元级采购争夺 H200 算力，同步调整 Claude 订阅定价引发开发者关注  
- **Pixelpoint 推出 Animate Text Skill** [3]：将 24 种文字动画固化为库无关 JSON 规格，实现 AI Agent 对视觉效果的**确定性执行**  
- **Waza 工程师技能合集重大更新** [5]：新增 Codex 支持、Agent Health 代码健康检查及增强思考模式  
- **OpenHuman 发布全自动个人知识库 Agent** [15]：连接 118+ 服务，每 20 分钟自动构建卡帕西式本地知识库，零手动维护
