# 5月12日 AI 速报 · 第 286 期

## Summary

## Content

## 🔍 核心洞察  
**AI 教育整合加速**、**编程 Agent 界面标准化**与**中国机构主导 ICLR 2026** 成为本周三大关键信号；清华以 **332 篇接收论文**登顶全球榜首，远超斯坦福与 MIT 总和 [5]；Coursera 与 Udemy 合并后估值达 **25 亿美元**，剑指 AI 驱动的终身技能重塑 [0]。

## 🚀 重点动态  
- **Coursera 完成对 Udemy 的收购，在线教育两大巨头合并** [0]：全股票交易落地，合并实体将整合课程库与认证体系，强化面向开发者与职场人的 AI 技能交付能力。  
- **Claude Code 上线 Agent View：统一管理所有 AI 编程会话** [1]：新界面支持后台任务调度、跨会话上下文切换及实时状态总览，降低多 Agent 协同认知负荷。  
- **Cursor 的优势与劣势：模型灵活性与自研模型缺失** [2]：宝玉指出其核心矛盾——**无自研顶尖模型**是短板，但**可自由调用任意第三方模型**构成差异化护城河。  
- **Codex 的野心：从 Agent 界面到插件生态的下一步** [3]：深度观察显示主流 Agent 工具界面趋同，平台化与开放**插件生态**已被视为下一阶段竞争分水岭。  
- **下个月的苹果 WWDC，假如 iCloud 变成 iClaw……?** [4]：文章呼吁 macOS 27 不应止步于 UI 优化，亟需构建系统级 AI 基建（如原生 Agent 运行时、AI 文件系统），迈向真正 **AIOS**。  
- **中国拿下这届 AI 顶会半壁江山，清华一家单挑斯坦福加 MIT** [5]：ICLR 2026 接收论文中，中国机构占比 **43.7%**，清华以 **332 篇**居首；实地调研揭示其**低组织摩擦**与**极致工程务实主义**文化优势。  
- **黄仁勋现身卡内基梅隆（CMU）大学！讲了整整 18 分钟** [6]：在毕业典礼演讲中强调“AI 不会取代人的目的”，呼吁毕业生保持动手力、拥抱不确定性，并重申 NVIDIA 的“加速计算”长期信仰。  
- **传可灵计划独立融资上市：300 亿美元的快手长出 200 亿美元的 AI 视频子公司** [7]：快手拟分拆 AI 视频业务可灵，200 亿美元估值反映市场对**多模态生成基建**商业化的高度认可，亦凸显视频大模型赛道资本热度。
