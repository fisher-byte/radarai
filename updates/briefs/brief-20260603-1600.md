# 6月3日 AI 速报 · 第 353 期

## Summary

微软在 Build 2026 上密集发布 MAI 模型家族、Surface RTX Spark Dev Box 本地工作站与 Project Solara Agent 终端，标志着 Windows 正式迈向 Agent 原生操作系统；与此同时，OpenAI 将 Codex 深度整合进 ChatGPT，并推出六类岗位插件，加速向企业级 AI Agent 工作流平台 转型 [1][2]。

## Content

## 🔍 核心洞察  
微软在 **Build 2026** 上密集发布 **MAI 模型家族**、**Surface RTX Spark Dev Box** 本地工作站与 **Project Solara Agent 终端**，标志着 Windows 正式迈向 **Agent 原生操作系统**；与此同时，**OpenAI 将 Codex 深度整合进 ChatGPT**，并推出六类岗位插件，加速向企业级 **AI Agent 工作流平台** 转型 [1][2]。

## 🚀 重点动态  
- **微软发布 Windows「梦中神机」：MAI 模型家族 + Surface RTX Spark Dev Box + Project Solara Agent 终端** [1]：一站式覆盖模型训练、本地推理与物理 Agent 执行的 AI 工作站生态正式落地  
- **ChatGPT 全面转向企业 Agent 平台，集成 Codex 并上线六类岗位插件与 Sites 功能** [2]：产品定位从对话入口升级为可编排、可部署的**工作流智能体中枢**  
- **制糖工厂发布 AI 小电拼 Mirror 充电器** [3]：全球首款支持 **MCP 协议** 与 **AI Agent 原生接入** 的能源硬件，将充电器定义为可编程**边缘能源节点**  
- **腾讯云 DeepSeek-V4 API 价格最高下调 97.5%** [3]：大幅降低企业调用高阶推理模型门槛，加速国产大模型在垂直场景规模化落地  
- **徕卡相机或被红杉中国主导收购** [3]：消费影像领域标志性品牌或将迎来中国资本深度整合，引发光学+AI 硬件协同新猜想
