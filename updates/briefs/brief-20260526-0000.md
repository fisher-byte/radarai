# 5月26日 AI 速报 · 第 327 期

## Summary

DeepSeek 以永久降价的 V4-Pro API 发起低价冲击，剑指Claude Code级编程 Agent 市场；面壁智能突破端侧瓶颈，实现600亿参数模型在昇腾平台的1.58-bit三值量化训练，显存节省6倍且保留97%能力 [2]；与此同时，Gemini悄然变更计费逻辑，付费用户实际额度大幅缩水，暴露大模型商业化中的信任裂痕 [10]。

## Content

## 🔍 核心洞察  
**DeepSeek** 以永久降价的 V4-Pro API 发起低价冲击，剑指**Claude Code**级编程 Agent 市场；**面壁智能**突破端侧瓶颈，实现**600亿参数模型**在昇腾平台的**1.58-bit三值量化**训练，显存节省6倍且保留97%能力 [2]；与此同时，**Gemini**悄然变更计费逻辑，付费用户实际额度大幅缩水，暴露大模型商业化中的信任裂痕 [10]。

## 🚀 重点动态  
- **DeepSeek 要用蜜雪冰城的打法，做中国版 Claude Code** [0]：V4-Pro 模型 API 永久降价，同步推进类 Claude Code 的 AI 编程 Agent 工具研发。  
- **将 600 亿参数大模型装进手机的瓶颈，终于被中国 AI 公司突破了** [2]：面壁智能联合清华、OpenBMB 发布 BitCPM-CANN 三值模型，在华为昇腾实现端到端训练。  
- **Gemini 也叛变了，付费用户变小丑** [10]：谷歌将 Gemini 计费模式从按调用条数改为按算力消耗，并引入双重限额，引发大规模用户抗议。  
- **RenderFlow：百度垂类搜索展现服务的 Agentic 代码交付实践** [9]：百度落地 LLM 驱动的 Agentic 系统，单场景代码交付周期从天级压缩至分钟级。  
- **蚂蚁集团领投，光轮智能 20 亿美元估值引领全球具身数据基础设施** [6]：具身智能产业价值重心加速向**数据与评测基础设施**迁移。  
- **重磅！“AIGC 绘画-人物设计白皮书-第一辑”今日发布！** [4]：首份 AIGC 人物视觉词典，系统梳理发型/发饰/服饰中英文术语及示例图谱。  
- **今日开源（2026-5-25）：微软 Lens 正式开源，3.8B 参数基础文本转图像模型** [5]：含密集字幕预训练与混合分辨率学习能力的 T2I 开源基座发布。  
- **年轻人不买精修图，景区旅拍开始慌了** [8]：AI 修图工具普及打破信息差，倒逼旅拍行业重构定价与服务逻辑。
