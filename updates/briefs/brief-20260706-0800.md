## 🔍 核心洞察  
AI 基础设施正经历关键拐点：**Meta 开放 GPU 算力**商业化、**华为韬定律论文升级**披露 LogicFolding 3D 堆叠细节、**北京大学忆阻器芯片**实现存内计算突破，而**HBM 之父金正浩**直指 GPU 利用率仅 **10%** 的内存瓶颈本质 [2][5][15][22]。

## 🚀 重点动态  
- **Jaade：macOS 本地 coding agent 工作台上线** [1]：整合 Claude Code/Codex 会话、终端与 Git，实现 AI 编程过程「**可视可控**」，终结黑盒化困局。  
- **Meta 计划对外出售 AI 算力** [2]：因自研模型进展滞后，转向将庞大基础设施变现，被市场视为「**卖铲子战略**」，推动股价大涨。  
- **华为发布韬定律论文第二版** [5]：详述 **LogicFolding 3D 堆叠技术**与 AI 数据中心「三件套」工程权衡，强化国产算力基建方法论输出。  
- **北大/中科院推出全球首款可控存内计算芯片** [22]：基于相变忆阻器，**0.43 秒完成大脑皮层建模**，速度达 GPU 的近 500 倍。  
- **美团 LongCat-2.0 开源** [14]：**1.6 万亿参数 MoE 大模型**，纯国产卡（5 万张）训练，Agent 基准表现对标 Gemini 3.1 Pro。  
- **SeKV 长文本推理新法问世** [23]：英属哥伦比亚大学与微软提出语义分段+SVD 技术，**24G 显卡可处理近 300K 文本**，显存占用降 53%。  
- **Browser Relay 开源项目发布** [21]：让任意 AI Agent 直接操控用户**带完整登录态的真实 Chrome 浏览器**，打通本地操作闭环。  
- **黑客利用 SEO 投毒实施 AI Agent 提示注入攻击** [20]：通过隐藏 HTML 与恶意网页排名，诱骗 Agent 执行欺诈支付等高危指令。
